## 📋 Overview

**eat-n-split** is a React-based app that simplifies splitting expenses with friends. It allows you to:

- Select friends from a list
- Split bills based on who paid
- View updated balances
- Add new friends on the fly
- Enjoy responsive, clean UI interactions

## ⚙️ Core Features

- 👥 **Friend Management** – Add, view, and select friends to split bills with.
- 💳 **Bill Splitting** – Enter bill value, your expense, and payer to auto-split.
- 🔁 **Live Balance Updates** – Updates each friend’s balance in real-time.
- 🎯 **Interactive UI** – Dynamic feedback with fun emojis and validations.
